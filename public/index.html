Heads up: this runs on a free-tier host and a free LLM API. First request after idle may take ~30s to wake, and there's a rate limit of 15 requests/minute. It's a portfolio demo, not a production service.

API Reference

POST /api/extract

Extracts structured data from unstructured text. Send a JSON body with the text and the extraction type.

fieldtypedescription
textstringThe raw text to extract from. Required. Max 8000 chars.
typestringOne of: job_posting, product, contact. Defaults to job_posting.

Example request

curl -X POST https://YOUR-URL/api/extract \
  -H "Content-Type: application/json" \
  -d '{
    "type": "job_posting",
    "text": "Senior Backend Engineer at Acme, remote. Node.js and PostgreSQL required."
  }'

Example response

{
  "type": "job_posting",
  "data": {
    "title": "Senior Backend Engineer",
    "company": "Acme",
    "location": "Remote",
    "remote": true,
    "seniority": "senior",
    "required_skills": ["Node.js", "PostgreSQL"],
    "employment_type": null
  }
}

GET /api/health

Returns service status. Used for uptime checks.
